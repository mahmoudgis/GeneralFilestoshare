# أداة تحميل بيانات بوابة مؤشرات التنمية المستدامة (UAE SDGs Data Hub)

المصدر: https://sdgsuae-fcsa.opendata.arcgis.com — بوابة ArcGIS Hub تابعة للهيئة الاتحادية للتنافسية والإحصاء.

## ملاحظة مهمة عن الشبكة

المضيف `sdgsuae-fcsa.opendata.arcgis.com` محجوب حالياً بواسطة سياسة الخروج (egress policy) لبيئة التشغيل السحابية،
لذلك لم يتم تنفيذ التحميل الفعلي من داخل الجلسة. الأداة أدناه جاهزة وتعمل، وتحتاج فقط إلى بيئة يُسمح فيها بالنطاقات التالية:

- النطاق الأول: `sdgsuae-fcsa.opendata.arcgis.com` (فهرس البوابة)
- النطاق الثاني: `www.arcgis.com` (تحميل ملفات المستندات)
- النطاق الثالث: `services*.arcgis.com` و`*.arcgis.com` (خدمات الطبقات الجغرافية)

## طريقة الاستخدام

الأمر الأول لجلب الفهرس فقط (سريع، بدون بيانات):

```bash
python3 tools/fetch_sdg_hub.py --catalog-only --out data/sdg_uae
```

الأمر الثاني لتحميل كل البيانات (GeoJSON + CSV + المستندات):

```bash
python3 tools/fetch_sdg_hub.py --out data/sdg_uae
```

الخيارات المتاحة:

- الخيار `--formats geojson,csv` لتحديد صيغ الإخراج للطبقات الجغرافية.
- الخيار `--limit N` لاختبار الأداة على أول N عنصر فقط.
- الخيار `--overwrite` لإعادة تحميل الملفات الموجودة (الوضع الافتراضي هو التخطي والاستئناف).
- الخيار `--sleep` لضبط فترة الانتظار بين العناصر تفادياً للحد من المعدل.

## المخرجات

المجلد الناتج يحتوي على:

- الملف `catalog.json` و`catalog.csv`: فهرس كامل بكل عناصر البوابة (العنوان، النوع، الوسوم، الرابط، تاريخ التحديث).
- المجلد `datasets/`: ملف `.geojson` وملف `.csv` لكل طبقة جغرافية، وملفات PDF/XLSX للمستندات.
- الملف `manifest.json`: سجل تفصيلي لكل عنصر (عدد المعالم، نوع الهندسة، الأخطاء إن وُجدت).

## آلية العمل

الأداة تعتمد ثلاث واجهات برمجية عامة:

1. الواجهة الأولى `/api/search/v1/collections/all/items` لاستخراج فهرس البوابة مع الترقيم التلقائي.
2. الواجهة الثانية `/FeatureServer/<layer>/query` لسحب المعالم على دفعات باستخدام `resultOffset` مع إسقاط الإحداثيات إلى WGS84.
3. الواجهة الثالثة `arcgis.com/sharing/rest/content/items/<id>/data` لتحميل المستندات والملفات.

المكتبات المطلوبة: لا شيء خارج مكتبة بايثون القياسية (Python 3.9 فما فوق)، والأداة تحترم إعدادات `HTTPS_PROXY` و`SSL_CERT_FILE`.
